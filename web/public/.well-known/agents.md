# Elicita — Inteligencia de Contratación Pública

**URL:** https://elicita.es  
**Descripción:** Sistema de inteligencia sobre contratación pública española con 55M+ registros de licitaciones, adjudicaciones y empresas.

## Qué hacemos

Elicita indexa y analiza datos de contratación pública en España para ayudar a empresas, consultoras y profesionales a:

- **Buscar oportunidades** de negocio en licitaciones públicas
- **Analizar el mercado** de su sector geográfico
- **Monitorear competidores** y clientes potenciales
- **Predecir renovaciones** de contratos próximos a expirar

## API disponible

- **Endpoint:** `https://api.elicita.es/v1`
- **Autenticación:** Clerk (sign-up en https://elicita.es/sign-up)
- **Formatos:** JSON
- **Documentación:** https://elicita.es/docs/api

## Descubrimiento

- `/.well-known/api-catalog` — Catálogo de API (RFC 9485)
- `/.well-known/agent.json` — Metadata para agentes
- `/robots.txt` — Reglas de crawling (RFC 9309)
- `/sitemap-index.xml` — Sitemap XML

## Capacidades

- `search` — Búsqueda semántica de licitaciones
- `filter` — Filtrado avanzado por CPV, importe, fecha, lugar
- `alerts` — Alertas personalizadas por email
- `analytics` — Análisis de mercado y tendencias
- `export` — Exportación de datos
- `predictions` — Predicción de renovaciones
